## 实验分析
1. **UDP 还是 TCP**
QQ同时用到两种：登录/消息常使用 **UDP**；大文件传输、部分可靠会话会使用 **TCP**。本次抓包可以观察到大量UDP报文，也有少量TCP。

2. **加密还是明文**
QQ聊天消息已经做了**私有加密 / TLS加密**；抓包中看不到聊天明文，无法直接读出聊天内容。

3. **恢复可能明文传输的文件（特征码思路）**
不同类型文件有固定头部特征码（例如PNG：`89 50 4E 47`、JPEG：`FF D8 FF`）。
如果有文件以明文在TCP流里传输，可以在Wireshark →「追踪TCP流」，搜索这些特征码，把对应字节导出，尝试还原出文件；
但现在QQ传输文件也大多加密，很难直接恢复。

## 小结
QQ混合使用UDP、TCP；绝大多数消息与文件已经加密；文件还原依赖特征码，但加密后该方法很难奏效。
